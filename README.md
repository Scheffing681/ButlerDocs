# Butler Docs

The Silentium's Butler — Dokumente. A separate app next to Butler: documents, insurance, personal papers, calendar, tasks, banks, vault, book of life and estate.

- Own address and own home-screen icon (Butler Docs).
- Own data: every key is stored under the `bdocs:` prefix, own databases (`bdocs-*`) and own offline cache, so it never mixes with Butler on the same site.
- Built the same way as Butler: `node build.js`, `node tests/bump.js`, `node tests/smoke.js`.
- Only the original plan: `src/modules/docs/only-docs.js` closes every Butler part that is not about documents (wardrobe, fitness, health, places, growth, shopping, money planning…). Their data is not deleted.
- Сейф: `src/modules/docs/vault.js`. Without a code a separate shelf; with a code (4–8 digits) the list, files and scanned text of its documents are encrypted (PBKDF2 → AES-256-GCM). A forgotten code cannot be recovered.
- Behörden & Dienste: `src/modules/docs/behoerden.js` (home tile in place of «Aufgaben»; tasks stay in the calendar and in the bottom bar). Since v16 «simple»: only what the user adds himself — no emergency buttons, no ready-made sets, no prefilled addresses; three ways to add: from a scanned letter (letterhead: office, address, phone, reference numbers, ticked by the user; a later letter with a new address offers an update), by pasting a link, or by hand with one smart field (phone / e-mail / link recognised); dates are only suggested. Per entry a Termin link, own buttons and links, numbers to copy, secret numbers (encrypted with the vault code), opening hours with «open now», route, for whom, pin, «on the home screen». Booking always happens on the office's own site. 
- Finanzen: `src/modules/docs/finanzen.js` (home tile in place of «Banken»). Steuer-Mappe: receipts by photo per year and category (Arbeit, Handwerker & Haushalt, Gesundheit, Kinderbetreuung, Spenden, Versicherungen & Vorsorge, Sonstiges) with short «Gut zu wissen» rules (always «bitte prüfen»), year sums and one PDF (overview + every receipt) for ELSTER or the Steuerberater. Bank accounts become cards in «Behörden & Dienste» once (IBAN, BIC, card, online banking, block number); `g.fin` stays as it is.

Tab «Verträge & Kosten» in Finanzen: all contracts per month and year, hints (notice date within 60 days, two contracts of the same kind, no amount, old contracts → check price), each opens its own card. Home tile «Arbeit & Karriere» (9th tile): employers with dates, documents tied to each (fitting ones suggested), projects with result, one PDF list for applications.
